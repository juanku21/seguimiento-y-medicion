# Frontend de Software Metrics & Estimation

Aplicación web del proyecto, construida con Next.js y Tailwind CSS.

La documentación del proyecto se mantiene en un único lugar, el [`README.md` de la raíz](../README.md), para no duplicar pasos que se desactualicen. Las secciones que corresponden al frontend son:

- [Arquitectura y Stack Tecnológico](../README.md#arquitectura-y-stack-tecnológico): stack y organización de capas bajo `src/`.
- [3. Crear los archivos de entorno](../README.md#3-crear-los-archivos-de-entorno): `frontend/.env.local` para desarrollo y `frontend/.env.test` para las pruebas.
- [7. Ejecutar el frontend](../README.md#7-ejecutar-el-frontend): instalación de dependencias y servidor de desarrollo.
- [9. Ejecutar las pruebas](../README.md#9-ejecutar-las-pruebas): Vitest, ESLint y comprobación de tipos.
- [10. Ejecución con Docker](../README.md#10-ejecución-con-docker): ejecución con el `Dockerfile` de esta carpeta.
- [Cobertura de Pruebas](../README.md#cobertura-de-pruebas): reporte de cobertura del frontend.
